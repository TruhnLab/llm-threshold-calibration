\section{Prompts}\label{sec:prompts}
Each label was queried in a separate context. The placeholder \texttt{\{finding\}} was replaced by the label phrase listed in Section~\ref{sec:labels}. The image was passed together with the prompt.

\subsection{JSON schema for guided decoding}
The text-elicited probability was generated with guided decoding (xgrammar) constrained to the following JSON schema, which only admits numbers with three decimal places (all observed values lay between 0 and 1):
\begin{lstlisting}
{"type": "object",
 "properties": {"probability": {"type": "string", "pattern": "[01]\\.\\d{3}"}},
 "required": ["probability"]}
\end{lstlisting}
